# Frontend UI/UX Review

## Objective

Review the frontend from the perspective of an experienced Frontend Engineer and UX Reviewer.

Focus on usability, consistency, accessibility, responsiveness, and maintainability.

Do not change backend code.

---

Read:

- docs/01-requirements/
- docs/02-design/
- docs/03-api/
- docs/08-ai/project-status.md

Understand the purpose of every implemented page.

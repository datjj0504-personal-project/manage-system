After the frontend starts successfully:

Use the browser to perform end-to-end verification.

For every implemented page:

- Open the page.
- Interact with every form.
- Click every button.
- Submit valid and invalid data.
- Verify the expected UI.
- Inspect browser console.
- Inspect network requests.
- Verify backend responses.

If any issue is found:

- Explain the root cause.
- Apply the minimal fix.
- Restart the frontend if required.
- Repeat the verification.

Continue until every implemented frontend feature passes verification.

Produce a final QA report with:

- Tested pages
- Passed scenarios
- Failed scenarios
- Remaining issues
- Files modified

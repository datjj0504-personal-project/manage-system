# Glossary

| Term | Description |
|-------|-------------|
| User | Registered account |
| Project | Workspace containing tasks |
| Member | User participating in a project |
| Owner | User who created the project |
| Admin | User with management permissions |
| Assignee | User responsible for completing a task |
| Task | Unit of work |
| Status | Current task state |
| Priority | Task importance |
| Attachment | Uploaded file |
| Comment | Discussion under a task |
| DTO | Data Transfer Object |
| Entity | Persistence model |
| Repository | Data access layer |
| Service | Business logic layer |
| Controller | HTTP endpoint layer |
| JWT | JSON Web Token |
| API | Application Programming Interface |
| Soft Delete | Mark data as deleted instead of removing it |
| Pagination | Divide large datasets into pages |
| Sorting | Ordering returned data |
| Filtering | Returning partial datasets |
| Validation | Request input verification |
| Audit | Record system activities |

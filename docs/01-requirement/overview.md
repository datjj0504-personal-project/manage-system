# Task Management System

## Objective

Build a production-ready Task Management System to learn Java Backend development using Spring Boot.

The project follows enterprise-level coding standards and architecture.

The main goals are:

- Learn Java Core
- Learn Spring Boot
- Learn REST API
- Learn Spring Security
- Learn JPA/Hibernate
- Learn Database Design
- Learn Docker
- Learn Testing
- Learn Clean Architecture
- Learn CI/CD (future)

The project should be maintainable, scalable and easy to extend.

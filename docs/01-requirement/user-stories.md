# User Stories

## Authentication

- As a `User`, I want to register an account so that I can access the system securely.
- As a `User`, I want to log in so that I can receive JWT credentials for authenticated access.
- As a `User`, I want to refresh my token so that I can continue using the API without logging in again too frequently.

## User Profile

- As a `User`, I want to view my own profile so that I can confirm my account information.
- As a `User`, I want to update my profile so that my personal information remains accurate.
- As a `User`, I want to change my password so that I can protect my account.
- As a `User`, I want to update my avatar so that my profile is easier for other project members to recognize.

## Project

- As a `User`, I want to create a `Project` so that I can organize related work in one workspace.
- As a `Member`, I want to view `Project` details so that I can understand project context and membership.
- As a `Member`, I want to list accessible `Project` items so that I can navigate the workspaces I belong to.
- As an `Owner`, I want to update a `Project` so that project information stays correct.
- As an `Owner`, I want to delete a `Project` so that I can remove unused workspaces.

## Task

- As a `Member`, I want to create a `Task` in a `Project` so that work can be tracked.
- As a `Member`, I want to update `Task` details so that title, description, `Status`, `Priority`, and due date remain accurate.
- As a `Member`, I want to assign a `Task` to an `Assignee` so that responsibility is clear.
- As a `Member`, I want to list `Task` items by Pagination, Sorting, and Filtering so that I can find work efficiently.
- As a `Member`, I want to view `Task` detail so that I can understand the current work item completely.

## Collaboration (Planned)

- As a `Member`, I want to add a `Comment` to a `Task` so that project communication stays attached to the work item.
- As a `Member`, I want to attach files to a `Task` so that supporting documents are available in context.

## Administration (Planned)

- As an `Admin`, I want elevated management capabilities so that I can support project governance when needed.
